## Overview
Redesign the AYLA Construction LTD website from the current luxury dark theme to a professional, premium, trustworthy light theme suitable for a UK construction company.

## Brand Identity
- **Primary Color:** #1F4E79 (dark blue)
- **Secondary Color:** #3F6FA6 (medium blue)
- **Accent Colors:** #8CB6DE, #D6E6F5 (lighter blues)
- **Text Colors:** #1F1F1F (dark), #6B7280 (gray)
- **Backgrounds:** #FFFFFF (white), borders #E5E7EB (light gray)
- **Style:** Professional, premium, trustworthy, clean layouts, strong hierarchy, generous spacing, subtle blue gradients, modern, calm, confident

All 4 Astro components have been successfully redesigned with the professional blue theme:

#### 1. FeaturedProjects.astro
- Changed background from `bg-charcoal` to `bg-gray-50`
- Updated all gold colors (`#C9A962`) to blue palette (`#1e3a8a` - blue-900)

- Updated body text from `text-cream/60` to `text-gray-600`
- Redesigned "View All Projects" button with `btn-primary` class and clean blue styling (bg-blue-900, hover:bg-blue-800)
- Removed corner accent decorations for cleaner look
- Updated background patterns to use blue colors with minimal opacity

#### 2. Testimonials.astro

#### 3. FAQ.astro
- Changed background from `bg-charcoal` to `bg-gray-50`
- Updated accordion cards with `card-professional` class
- Changed borders from `border-cream/10` to `border-gray-200`
- Updated question numbers from `text-gold/40` to `text-blue-900/40`
- Changed headings from `text-white` to `text-gray-900` with `hover:text-blue-900`
- Updated expand/collapse icon with blue colors: border `border-blue-900/30`, open state `bg-blue-900 text-white`
- Changed answer text from `text-cream/60` to `text-gray-600`
- Updated CTA link from gold to `text-blue-900 hover:text-blue-800`

#### 4. Contact.astro
- Changed background from `bg-cream` to `bg-white`
- Updated form container with `card-professional` class and `bg-gray-50` background
- Changed form inputs from cream backgrounds to white with `border-gray-300`
- Updated focus states to use blue: `focus:border-blue-900 focus:ring-1 focus:ring-blue-900`
- Redesigned submit button with `btn-primary` class (bg-blue-900, hover:bg-blue-800)
- Changed contact information sidebar from `bg-charcoal` to `bg-blue-900`
- Updated all icon colors and borders to use blue/white palette
- Changed service dropdown arrow color to blue (#1e3a8a)

### Key Design Principles Applied
- **Clean Layouts:** Removed decorative corner accents and glass effects
- **Professional Color Palette:** Consistent use of blue-900 (#1e3a8a) and gray tones
- **Clear Hierarchy:** Strong contrast between headings (gray-900) and body text (gray-600)
- **Subtle Accents:** Light blue decorative elements with very low opacity
- **Consistent Classes:** Used `btn-primary`, `card-professional`, and `blue-line` classes
- **Trustworthy Feel:** White/light gray backgrounds with professional blue accents

All components now present a cohesive, professional appearance suitable for a UK construction company while maintaining the same structure and functionality.
